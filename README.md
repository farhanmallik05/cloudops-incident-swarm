# Strands SDK: Workshop to Ship (AWS Builder Center)

> **Event Window:** October 28, 2026 – November 4, 2026 | **Status:** Live  
> **Challenge Type:** Advanced AI Agents & Systems Challenge  
> **Hosting Platform:** AWS Builder Center  
> **Core Theme:** *"Take the workshop, Building AI Agents with Strands SDK: From Simple Loops to Multi-Agent Swarms, then build and ship a production AI agent system on AWS."*

---

## 📌 Executive Summary

The **Strands SDK: Workshop to Ship** challenge is a flagship AI systems hackathon on AWS Builder Center. The challenge bridges the gap between prototyping local agent loops and shipping enterprise-ready multi-agent swarms. Builders leverage the open-source **Strands Agents SDK** (Python/TypeScript), **Amazon Bedrock foundation models** (such as Anthropic Claude 3.5 Sonnet / Haiku), and **Bedrock AgentCore / AWS Serverless** infrastructure to solve complex, multi-step autonomous workflows.

## 🚀 Quick Launch (How to Use This Plan)

1. Review [`plan/01_CHALLENGE_OVERVIEW.md`](./plan/01_CHALLENGE_OVERVIEW.md) and [`plan/02_STRANDS_SDK_DEEP_DIVE.md`](./plan/02_STRANDS_SDK_DEEP_DIVE.md) to understand Strands SDK primitives.
2. Select an agent swarm concept from [`plan/03_PROJECT_IDEAS_AND_AGENT_SWARMS.md`](./plan/03_PROJECT_IDEAS_AND_AGENT_SWARMS.md) (we strongly recommend **CloudOps Swarm: Autonomous AWS Incident Triaging & Remediation**).
3. Copy the production starter code from [`plan/STARTER_AGENT_CODE.md`](./plan/STARTER_AGENT_CODE.md).
4. Follow [`plan/05_AWS_BEDROCK_AND_AGENTCORE_INTEGRATION.md`](./plan/05_AWS_BEDROCK_AND_AGENTCORE_INTEGRATION.md) to configure Amazon Bedrock and AWS credentials.
5. Deploy and record your 3-minute demo pitch using [`plan/07_SUBMISSION_AND_DEMO_GUIDE.md`](./plan/07_SUBMISSION_AND_DEMO_GUIDE.md).
